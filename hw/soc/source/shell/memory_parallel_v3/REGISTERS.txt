Memory Parallel V3 hardware counter ABI 1.2
==========================================
Uncached CBUS MMIO: base 0x02020000, size 0x10000. One CPU-owned selector.
All offsets below are relative to that base. Aligned 32-bit control writes;
64-bit reads, or two aligned 32-bit reads, for the 64-bit read-only fields.

Offset  Width Access  Meaning
0x00    64    RO      0x4d50563300010002: "MPV3", ABI 1.2
0x08    32    WO      COMMAND: 1 START, 2 STOP, 3 CLEAR, 4 SNAPSHOT
0x10    64    RO      STATUS bit0 busy, bit1 enabled, bit2 snapshot_valid,
                     bit3 external_available, bit4 invalid_command
0x18    64    RO      Completed snapshot sequence, low 32 bits (wraps)
0x20    32    RW      SELECT: block_id*32 + counter_slot (low 9 bits)
0x28    64    RO      Frozen selected counter; zero while busy/invalid
0x30    64    RO      Bank-select address mask = 0x3000
0x38    64    RO      Total L2 bytes = 1048576
0x40    64    RO      SoC counter domain frequency = 100000000 Hz
0x48    64    RO      DDR counter domain frequency = 300000000 Hz
0x50    64    RO      Number of counter blocks = 16
0x58    64    RO      Number of L2 banks = 4
0x60    64    RO      Common memory datapath width = 512 bits
0x68    64    RO      Ordinary MSHRs PER BANK = 32
Other offsets are reserved. All sixteen block selectors are used.

Commands and ordering
---------------------
Reset disables measurement and invalidates snapshots. START resumes without
clearing. STOP stops accumulation but does not create a snapshot. CLEAR
stops measurement, zeros statistics and frozen values, and invalidates the
snapshot; it does not reset the sequence or functional request tracking.
SNAPSHOT freezes all blocks while preserving the current measurement state.
It invalidates DATA during collection, sets valid and increments sequence
only when both clock domains have acknowledged. Commands issued while busy
or external_available=0 wait at the MMIO interface. Unsupported command
values set invalid_command without starting a command; a valid command
clears that flag. Values are not returned until a completed valid snapshot.

Software handoff sequence (no driver implementation):
  Read version and external_available. CLEAR; wait busy=0. START; wait busy=0.
  Run workload. STOP; wait busy=0. SNAPSHOT; wait busy=0 and valid=1.
  Save sequence. For each selector, write SELECT, then read DATA.
  Read DATA low at 0x28 and high at 0x2c if only 32-bit MMIO is available.
  Recheck sequence after the set of reads. Serialize selector/commands across
  software users and apply the platform's normal device-MMIO ordering rules.

Frozen registers remain stable until CLEAR, SNAPSHOT or reset. Ordinary
counters wrap modulo 2^64. Peaks retain the maximum since CLEAR. Slot 31
is a free-running local-domain timestamp captured with the snapshot; only
hardware reset zeros that clock, not CLEAR. The epoch/sequence associates
the snapshots, but 100/300 MHz domains do not sample on the same edge.
Event and command staging are aligned inside each counter block. Measurement
commands are acknowledged after staging settles in both domains.
External reset invalidates the front-end snapshot and stops local counters.

Blocks
------
0,1,2 Gemmini0,1,2; 3 CPU DCache/ICache/vector memory;
4 FBus (all ID groups); 5 L2 bank0; 6 L2 bank1; 7 SoC AXI before Head;
8 DDR S00 after Head, before CDC; 9 MIG after the full register slice;
10 video S01 (writer AW/W/B + reader AR/R); 11 idle S02; 12 Head router; 13 independent Tensor writer; 14 L2 bank2; 15 L2 bank3.
Blocks 9..11 use 300 MHz; all others use 100 MHz. Block 11 is reserved for
the existing tied-off S02 port and reports no requests. Slot 0 and 31 still
report measurement cycles and time. Unlisted counter slots return zero.

Slots for blocks 0..4 and 13 (clients)
--------------------------
0 enabled cycles (once per SoC cycle, not twice for two banks)
1 A requests (first beat); 2 Get/AcquireBlock read requests; 3 Put requests
4 requested read bytes; 5 accepted A data bytes (mask popcount)
6 A valid/not-ready bank-cycles; 7 accepted D data bytes (size-limited)
8 D valid/not-ready bank-cycles; 9 accepted C beats; 10 C stalled bank-cycles
11 A requests to bank0; 12 A requests to bank1; 13 completed D messages
14 A requests to bank2; 15 A requests to bank3; 31 local timestamp
The sum of stalls across banks can be 4 in a cycle. AcquirePerm is counted
in A requests but not requested read bytes. C/D categories include coherence.
These taps observe L2 entrances, not the pre-arbitration Gemmini DMA ports.

Slots for blocks 5,6,14,15 (L2 banks)
-------------------------------
0 enabled cycles; 1 A requests; 2 accepted D beats; 3 D stall cycles
4 directory results; 5 directory hits; 6 directory misses
7 ordinary MSHR occupancy sum; 8 coherence MSHR occupancy sum
9 all 32 ordinary MSHRs occupied cycles; 10 scheduler request stall cycles
11 peak ordinary MSHR occupancy
12 secondary queue enqueues; 13 secondary queue enqueue stall cycles
14 outer D refill bytes; 15 outer C data writeback bytes
16 outer A stall; 17 outer D stall; 18 inner A stall
19 both banks accepted D beats in this cycle (same global value in 5 and 6)
31 local timestamp
Hits/misses include replay/control/coherence lookups, not a load miss rate.
Divide occupancy sums by slot 0 for average occupancy over the window.

Slots for blocks 7..11 (AXI)
---------------------------
0 enabled cycles; 1 AR accepts; 2 AW accepts; 3 R beats; 4 W beats; 5 B accepts
6 AR requested bytes, sum((ARLEN+1)<<ARSIZE); 7 W bytes, popcount(WSTRB)
8 AR stalls; 9 AW stalls; 10 R stalls; 11 W stalls; 12 B stalls
13 read in-flight occupancy sum; 14 write in-flight occupancy sum
15 peak read in-flight; 16 peak write in-flight; 17 accepted RLASTs
18 occupied R bus bytes (R beats * local bus bytes; includes narrow lanes)
31 local timestamp
Read tracking increments on AR and decrements on RLAST. Write tracking
increments on AW and decrements on B, independently of W arrival. Tracking
continues while measurement is disabled or CLEAR is issued. Slot 6 is request
volume; slot 18 is occupied bus width, not exact useful bytes for narrow reads.

Slots for block 12 (Head)
------------------------
0 enabled cycles; 1 Head AW accepts; 2 Head AR accepts
3 Head AW waiting for DDR write drain; 4 Head AR waiting for DDR read drain
5 local read requests; 6 local read responses; 7 local response stall cycles
8 local request stall cycles; 31 local timestamp

ABI1.2 extension and fallback
----------------------------
The two-bank fallback reports ABI1.1 (0x4d50563300010001), 14 blocks,
mask0x1000 and 524288 bytes. Existing block and slot meanings are preserved.
L2 slot19 always means bank0 AND bank1 returned D on the same cycle. New
slots20,21,22 count cycles with at least two, at least three, and all four
banks returning D respectively. Client slot13 remains completed D messages.
Bank selection is A13:A12, sets use A6:A11 and A14:A16, and the complete
bank/set period is 128 KiB. Ordinary MSHRs remain 32 per bank.
