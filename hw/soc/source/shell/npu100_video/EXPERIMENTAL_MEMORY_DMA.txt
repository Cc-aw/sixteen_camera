访存实验选项，2026-10-11

状态：DMA v2 暂缓推进，保留实现，默认关闭。
当前 3x32 生产源码配置使用上一版的访存参数；不得将 DMA v2 作为默认优化启用。

选项                              生产默认     DMA v2 实验
dma_row_prefetch_entries           0            4
dma_read_coalescing                false        true
scratchpad_dma_buffer_entries     2            4
scratchpad_ex_burst                0            3

0 项预取表示不插入行描述符队列；false 表示不实例化请求合并器。
缓冲 2 项与 burst=0 恢复基线缓冲容量及仲裁策略。
这些是 Scala elaboration 配置，修改后要重新生成 SoC RTL 才作用于硬件；
修改源码不会改变已导出的 RTL 或已经生成/下载的比特流。

保留的实验预设：
XCVU13PGemmini32x32PackedInferenceRamConfigs.experimentalMemoryDmaV2Config
该预设不被默认单 worker 或三 worker 配置引用，仅供明确选择的实验和现有功能测试使用。
以后单项实验可从 Configs.config.copy(...) 指定上表中的一个选项。
三路配置的统一选择点为 XCVU13PGemmini32x32PackedInferenceRamMultiConfigs.base；
只有明确开展实验时才改其配置来源，并使用独立导出/构建目录。

暂缓依据：相同测试配置的整网周期中位数，串行 +0.07%、按层同步并行
+0.19%、独立并行 +1.62%。独立并行五轮波动区间重叠，不能把 1.62% 当作
稳定退化幅度，但未证明整网收益。完整布局布线 WNS=-0.222ns、WHS=0.000ns；
用户接受负 setup 时序后单独写出实验比特流，不能称为时序通过版本。

保留上一版有效优化：每路 DMA 32 个在途请求、共享 L2 32 个普通 miss 槽、
DDR 32 个接受/下发额度和对应路由器并发控制。三路 32x32、100MHz 与原 SLR
策略保持现有生产设置。
