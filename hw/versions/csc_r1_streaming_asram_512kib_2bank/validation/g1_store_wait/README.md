# C1a 写回等待优化仿真

G1 功能回归 **PASS**；G2 / 物理决策 **INSUFFICIENT_EVIDENCE**。

相对之前减少 **63,569** 周期；相对 C0 改变 **-66（-0.000915%）**。三路独立功能仿真的逐路结果见 [summary.json](summary.json)，不代表共享访存吞吐或板上 FPS。

三路各一帧、每帧 166 stage，逐路 11,049 个原生命令/边界。全部 **11,441,748** 次 SPAD 读取及 **1,578,600** 个输出 beat、最终 SPAD 逐字节一致；原尺寸层和三路多帧 Accumulator 共 **6,029,312** 字节一致。全网省略 **48** 个完整 Input tile，Get 减少 **3,694,464 字节（4.1665%）**，Weight/Bias 数量及字节保持原值。

四种 DMA 模式 × 三路 × 三帧、原始配置/写入干扰、隔离模式切换、命中后第二 D beat denied/corrupt 与实际复位重放均通过。新增原生输出覆盖输入用例三路三帧均零命中，OFF/ON 事件和周期完全一致，证明不会等待自己的输出。关闭模式 411,621 条事件及周期与 C0 一致。303 项驻留生命周期、18 项 Store 范围边界检查，以及原有数值/协议负例和 G0 回归通过。

已发出的访存仍采用保守排空，且新增范围算术的面积、时序尚未测量。原型限定于冻结的合法原生 tiling；2,938 个卷积包的完整配置及 tile 通道数不超过 outer 通道上界已独立核对，任意畸形原生指令包不在支持范围。本轮未修改生产 SoC 或父候选，未综合、布局布线、生成 bitstream 或上板。当前仿真不含共享 DDR/ASRAM、CPU/RVV/PPU 周期，不能据此批准物理实现。
