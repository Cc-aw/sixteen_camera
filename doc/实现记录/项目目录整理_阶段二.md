# 项目目录整理：第二阶段

本阶段整理脚本、仿真平台和历史软件快照。根目录 Makefile 继续作为日常入口。
现有 README 内容按要求保留，旧 README 中的脚本路径以本记录及迁移映射为准。

## 脚本归类

| 目录 | 用途 | 常用入口 |
| --- | --- | --- |
| `scripts/build/` | 固件、比特流、工程配置 | `build_video_bitstream.sh`、`build_single4_video_yolov5nu.py` |
| `scripts/program/` | FPGA / 固件下载 | `download_bitstream.sh`、`download_single4_video.sh` |
| `scripts/check/` | 清单检查、elaboration、定向综合检查 | `check_production_manifest.tcl` |
| `scripts/test/` | 软件及 RTL 回归驱动 | `run_yolov5nu_multi_channel_tensor_dma_tests.sh` |
| `scripts/generate/` | SoC 生成同步、查找表及测试向量生成、Tensor 导出 | `generate_taihang_single4_rtl.sh` |
| `scripts/timing/` | 时序报告和实现实验 | `report_video_timing.tcl` |

原顶层 95 个脚本迁入上述六类。3×Gemmini64 专用流程整体迁入
`scripts/build/npu0918_video/`，LoopConv 诊断工具整体迁入
`scripts/test/sim_loopconv/`，保留各自的文件关系。

## 仿真归类

79 个原 `sim/` 顶层文件按被测功能分类，测试平台内容保持一致：

| 目录 | 数量 | 范围 |
| --- | ---: | --- |
| `sim/video/` | 25 | 摄像头、HDMI、显示、视频控制 |
| `sim/tensor/` | 13 | Tensor DMA、打包、接入和历史预处理 |
| `sim/memory/` | 15 | AXI、FBus、DDR、CDC 总线验证 |
| `sim/ppu/` | 24 | PPU、Head 存储、发布和缓存控制 |
| `sim/common/` | 2 | 通用 CDC 测试与 XPM FIFO 仿真模型 |

Tcl/Python/Shell 中的显式路径、动态测试名路径和综合快照复制逻辑同步更新。

## 历史软件快照

`dual_gemmini16_sw/` 迁入 `legacy/software/dual_gemmini16/`。
包内源码、依赖和测试保留；只调整其 Makefile 的两处外部板级软件/BSP 相对路径，
使其仍指向迁移前的位置。这些外部依赖是否安装与目录迁移无关。

实际固件仍从 `sw/` 构建。下载入口 `sw/run.sh` 已更新为调用分类后的构建脚本。

## 常用命令

```bash
make check SOC_VARIANT=single4
make firmware SOC_VARIANT=single4
make bitstream SOC_VARIANT=single4
make test-tensor
make test-video
make test-ppu SOC_VARIANT=single4

bash scripts/program/download_bitstream.sh --bitstream /实际路径/video_single4.bit
bash scripts/program/download_single4_video.sh
```

3×64 继续使用专用 0918 Tcl；其他 SoC 使用 Vivado 默认流程。
原脚本位置不保留重复入口，旧路径与新路径逐项记录在
[阶段二目录迁移映射.json](阶段二目录迁移映射.json)。已有 build 产物和冻结交付物未迁移。

## 验证记录

- 三种 SoC 清单检查通过，生产输入仍为 120 项 RTL、10 项 IP、6 项约束。
- single4 / triple64 比特流构建前检查通过。
- 0918 专用 Tcl 流程测试通过，包括时序判定和 DSP 分区检查。
- Shell / Python 语法检查、静态脚本/仿真路径检查通过。
- 32 份现有 README 的内容校验一致；所有仿真文件内容校验一致。
- 历史软件快照内容校验一致，仅 Makefile 外部依赖路径有调整。
- 历史快照三组 host tests 通过：调度、后处理、定点参考。
- Tensor DMA 回归通过，包括正常写入、overflow、abort drain 和 stall recovery。
- 视频回归与 PPU 发布回归通过。
- Tcl 语法完整性与 Git diff 空白检查通过。

本阶段不执行完整固件编译、综合布局布线或板级下载。
