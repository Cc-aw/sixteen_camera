3个NPU多路视频推理优化方案

核心目的： 解决单模型“怎么执行”，Runtime要解决多模型、多帧、多 NPU“什么时候执行、在哪里执行、数据放在哪里”。


1. 多摄像头输入管理（Camera Manager）（王志瑞）

    ├── 输入路数
    │
    │   // 支持16路Camera并行输入
    │   // 动态管理Camera ID与Frame ID
    │
    ├── Frame Descriptor管理
    │
    │   // 记录Camera ID、Frame ID、Timestamp
    │   // 管理图像格式、DDR地址、任务优先级
    │
    ├── 视频格式转换
    │
    │   // 支持YUV/RGB格式转换
    │   // 适配YOLO输入Tensor格式
    │
    ├── Frame Buffer管理
    │
    │   // 采用双Buffer/环形Buffer设计
    │   // 实现Camera采集与AI推理流水并行
    │
    ├── 时间同步
    │
    │   // 基于Timestamp保证16路视频帧同步
    │   // 支持多Camera时序一致性
    │
    └── 丢帧策略
        // 根据NPU负载动态调整
        // 优先保证实时性和关键帧处理


2. 多流任务管理（Stream Manager）（王志瑞）

    ├── Stream Context管理
    │
    │   // 为16路Camera建立独立Stream上下文
    │   // 管理Frame Queue、FPS、运行状态
    │
    ├── 多路Frame Queue
    │
    │   // 缓存各Camera输入Frame任务
    │   // 支持异步流水处理
    │
    ├── QoS管理
    │
    │   // 根据Camera重要程度设置任务优先级
    │   // 根据Deadline调整任务调度策略
    │
    └── 状态监控
        // 实时统计FPS、延迟、丢帧数量
        // 支持动态资源调整


3. ISP图像预处理优化，针对4K，8K考虑（王志瑞）

    ├── Resize加速
    │
    │   // 640×480输入转换为YOLO网络尺寸
    │   // VPU硬件完成双线性插值
    │   // 降低CPU计算压力
    │
    ├── Normalize处理
    │
    │   // UINT8数据转换为INT8/INT16格式
    │   // 融合量化处理
    │
    ├── LetterBox处理
    │
    │   // 保持目标比例完成输入尺寸调整
    │   // 满足YOLO输入要求
    │
    ├── Layout转换
    │
    │   // NCHW转换为NHWC格式
    │   // 匹配NPU计算阵列结构
    │
    └── 预处理融合
        // Resize、Normalize、Layout转换融合执行
        // 减少DDR数据访问次数


4. 异构资源调度管理（Heterogeneous Scheduler）（李嘉傲）

    ├── CPU/VPU/NPU统一调度
    │
    │   // 根据任务类型动态分配计算资源
│   // 实现异构计算资源协同
│
    ├── NPU Load Balance
    │
    │   // 动态检测三个NPU Cluster运行状态
│   // 避免单个NPU过载
│
    ├── Deadline调度
    │
    │   // 根据Frame Deadline进行实时调度
    │   // 保证30FPS实时推理要求
    │
    └── Frame级任务分配
        // Frame任务动态分配至NPU0/NPU1/NPU2
        // 避免网络层跨NPU数据传输


5. NPU推理运行管理（NPU Runtime）（范顺博）

    │
    │   // 执行Compiler生成的NPU指令
    │   // 管理Conv/GEMM/Activation计算
    │
    ├── 算子融合优化
    │
    │   // Conv+BN+SiLU融合
    │   // 降低Feature Map存储开销
    │
    ├── Layer Tiling
    │
    │   // 根据64×64阵列进行矩阵切分
    │   // 提高PE利用率
    │
    └── 数据复用优化
        //
        // Weight Stationary
        // Activation Reuse


6. 片上存储管理（Memory Manager）（雷雅彬）

    ├── DDR-SRAM层次管理
    │
    │   // 建立DDR、Global SRAM、Local Scratchpad三级存储体系
    │
    ├── Tensor生命周期管理
    │
    │   // 分析Feature Map生命周期
    │   // 实现Tensor空间复用
    │

    │
    │   // Load Buffer与Compute Buffer并行工作
    │   // 实现DMA与计算重叠
    │
    └── Weight Cache管理

        // 缓存模型权重

7. DMA数据搬运优化（DMA Manager）（王志瑞）

    ├── 多通道DMA
    │
    │   // Camera数据与NPU数据独立传输
    │
    ├── Burst Transfer
    │
    │   // 连续地址高速访问DDR
    │   // 提升数据传输效率
    │
    ├── Scatter-Gather DMA
    │
    │   // 支持多Camera数据交错访问
    │
    ├── Prefetch
    │
    │   // 提前加载下一阶段计算数据
    │
    └── Zero Copy
        //
        // 减少CPU参与
        // 实现Buffer直接映射
